근무표의 셀을 누르면 해당 날짜의 근무를 직접 수정할 수 있습니다. '미입력'은 실제 근무를 아직 입력하지 않은 날짜입니다.

연차 등록

연차는 원래 근무를 삭제하지 않고 별도 기록으로 덮어 표시합니다. 취소하면 원래 근무가 다시 표시됩니다.

데이터 관리

입력한 근무와 연차는 이 기기의 사파리 브라우저에 자동 저장됩니다. 다른 기기에서는 백업 파일을 옮겨 불러오세요. 앱 데이터 삭제 전에는 반드시 백업 파일을 저장하세요.
