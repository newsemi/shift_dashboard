# 근무현황판

아이폰 사파리에서도 사용할 수 있는 4인 근무표 웹앱입니다.

## 버전 관리
- 현재 버전: v1.7
- `index.html`: 현재 실행 파일 (v1.7)
- `index_v1.6.html`: v1.6 보관본
- 이전 버전 파일은 삭제하지 않고 보관합니다.
- 다음 업데이트부터 기존 파일을 `index_vX.Y.html`로 먼저 백업한 뒤 새 파일을 올립니다.

## 기능
- 월 이동 및 날짜별 4인 근무표
- 날짜/직원 셀을 눌러 근무 구분과 번호를 수정
- 직전 근무 번호의 다음 번호 자동 입력 (5 다음은 1)
- 연차 등록 및 취소, 원래 근무 기록 보존
- 연차자 발생 시 원래 휴무자는 유지하고 남은 두 근무자를 맞교대 주간/야간으로 자동 표시
- 오세영 개인 근무일지 생성: 근무일에는 전·후 근무자 약칭과 본인 근무 표시
- 개인 근무일지 TXT 다운로드 및 복사
- 아내분 공유용 개인 월간 근무표: 본인 근무만 아이콘으로 표시하고 공유 기능 제공
- 시급 입력 기반 급여 예상: 기본급, 맞교대 수당, 지정 공휴일 수당, 세전·세후 추정액
- 공휴일 근무일 직접 지정 및 취소
- 브라우저 자동 저장
- 백업 위치 선택: 로컬 JSON 다운로드 또는 GitHub 비공개 저장소 업로드
- JSON 백업 복원
- 모바일 화면 대응

## 개인 근무일지 규칙
- 오전: 전날 야간 근무자 / 본인 오전 근무 / 당일 오후 근무자
- 오후: 당일 오전 근무자 / 본인 오후 근무 / 당일 야간 근무자
- 야간: 당일 오후 근무자 / 본인 야간 근무 / 다음 날 오전 근무자
- 이름 약칭: 조덕진=진, 김재민=민, 조장행=행
- 휴무·연차는 본인 상태만 표시

## 급여 계산의 초기 가정
- 일반 근무 기본 시간: 8시간
- 맞교대 기본 시간: 8시간
- 맞교대 주간 추가: 3시간 × 시급 × 1.5
- 맞교대 야간 추가: 4시간 × 시급 × 1.5
- 지정 공휴일 근무: 해당 근무의 전체 근무시간 × 시급 × 1.5 추가
- 세후는 사용자가 입력한 예상 공제율을 적용한 참고치이며 실제 급여명세와 다를 수 있습니다.
- 공휴일 근무일은 현재 직접 지정하는 방식입니다. 회사의 수당 중복 및 실제 인정시간 규정에 맞춰 추후 조정할 수 있습니다.

## GitHub 백업 설정
1. GitHub에서 Fine-grained personal access token을 생성합니다.
2. Repository access는 Only select repositories로 설정하고 `shift_dashboard_backup`만 선택합니다.
3. Repository permissions에서 Contents를 Read and write로 설정합니다.
4. 근무현황판의 백업 저장 위치를 GitHub로 선택하고 토큰을 입력한 뒤 백업 저장을 누릅니다.
5. 토큰은 브라우저에 저장되지 않으며 페이지를 새로 열면 다시 입력해야 합니다.

백업 파일은 비공개 저장소의 `backups/` 폴더에 날짜·시간별로 추가됩니다. 저장소가 Private인지 반드시 확인하세요.

## 데이터 안내
- 근무/연차 및 급여 설정은 기기의 브라우저에 자동 저장되며 자동 동기화되지 않습니다.
- GitHub 백업 파일은 비공개 저장소에 보관됩니다.
- 토큰은 웹앱에서 저장하지 않습니다. 토큰을 다른 사람에게 공유하지 마세요.
