# 근무현황판

개인 근무 확인과 동료 근무 확인을 위한 단일 HTML 앱입니다.

## 현재 포함된 기능

- 월별 근무표 보기
- 날짜별 개인 근무 직접 입력/수정
- 연차 등록 및 취소
- 브라우저 자동 저장
- JSON 백업 저장 및 불러오기

## 실행 방법

저장소의 `index.html`을 내려받아 브라우저에서 열면 됩니다.
현재 저장소는 비공개이므로 GitHub Pages 공개 웹주소는 아직 설정하지 않았습니다.

## 데이터 주의사항

- 초기 데이터는 대화에서 확인된 2026년 11월 1~3일 일부 근무만 포함합니다.
- 나머지 날짜는 임의로 채우지 않고 '미입력'으로 표시합니다.
- 입력한 내용은 현재 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터 삭제 전 JSON 백업을 권장합니다.
